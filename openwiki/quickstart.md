# Quickstart

Welcome to the **CraftMatch Flutter Web/Desktop Frontend** repository wiki. This repository contains the cross-platform frontend client written in Dart using the Flutter framework, configured for Web, Mobile, and Desktop target compilation.

The application serves as the user-facing web portal for Clients looking to find artisans and Workers (artisans) looking to manage their availability and work schedules.

## Scope of this Wiki
This wiki documents **only** the `artisansApp_frontend` repository. It focuses on the Flutter application widgets, routing setup, state management (e.g. Riverpod/Provider if used), Supabase client integrations, web assets, and deploy pipelines. For backend API endpoint implementations or Supabase server-side schema migrations, please refer to the shared [CraftMatch Docs](file:///c:/Users/user/Downloads/FinalYearProject/CraftMatch_Docs/generated-wiki-index.md).
